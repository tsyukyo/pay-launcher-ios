# 決済ランチャー：セットアップ手順

設定はWebアプリ（PWA）で作り、iPhoneの「決済ランチャー」ショートカットがその設定を読んでメニューを出します。ショートカットは最初に1回作るだけで、アプリの追加・削除・並べ替えはPWAで行います。

## 全体の流れ

1. PWAをHTTPSで公開し、iPhoneのホーム画面に追加する
2. 「決済ランチャー」ショートカットを作る（1回だけ）
3. PWAでアプリを選んでグループ分けし、「連携」タブの「ショートカットに送る」を押す
4. 以後はショートカット（アクションボタン、ウィジェット、Siri）かPWAの「起動」タブから使う

## 1. PWAの公開

このリポジトリをGitHub Pagesで公開します。公開URLは **https://tsyukyo.github.io/pay-launcher-ios/** です。

初回だけ、GitHubのリポジトリ画面で **Settings → Pages** を開き、Source を「Deploy from a branch」、Branch を `main` と `/ (root)` にして Save します。数分で上のURLが開けるようになります。

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体（起動画面と、編集・連携の画面） |
| `manifest.webmanifest` | ホーム画面に追加したときの名前とアイコン |
| `sw.js` | オフラインでも開けるようにするキャッシュ |
| `icon-180.png` / `icon-192.png` / `icon-512.png` | アイコン |
| `.nojekyll` | GitHub Pagesでファイルをそのまま配信するための空ファイル |

iPhoneのSafariで公開したURLを開き、共有ボタンから「ホーム画面に追加」を選びます。設定は端末内（localStorage）に保存されるので、ホーム画面に追加したPWAで編集してください。Safariのタブとホーム画面のPWAでは、保存場所が別になります。

## 2. 「決済ランチャー」ショートカットの作り方

ショートカットAppで新規作成し、名前を **決済ランチャー** にします。PWAの「連携」タブで名前を変えた場合は、その名前に合わせてください。

ショートカットの詳細設定（ⓘ）で「入力を受け取る」をオンにし、種類を **テキスト** にします。PWAから送られた設定を受け取るために必要です。

アクションを次の順に並べます。

1. **もし**：「ショートカットの入力」が「任意の値」（値がある）
    1. **ファイルを保存**：入力＝ショートカットの入力。「保存先を尋ねる」をオフ、保存先を `Shortcuts` フォルダにし、サブパスを `payment-launcher.json`、「上書き」をオンにする
    2. **通知を表示**：`設定を保存しました`
    3. **ショートカットを停止**
2. **終了（もし）**
3. **ファイルを取得**：`Shortcuts` フォルダから `payment-launcher.json`。「見つからない場合にエラー」はオン
4. **入力から辞書を取得**：入力＝ファイル　→ 変数名「設定」として扱う
5. **辞書の値を取得**：キー `order`、辞書＝設定
6. **リストから選択**：プロンプト `カテゴリ`　→ 結果を「カテゴリ」とする
7. **辞書の値を取得**：キー `apps`、辞書＝設定
8. **辞書の値を取得**：キー＝「カテゴリ」（変数）、辞書＝手順7の結果
9. **リストから選択**：プロンプト `アプリ`　→ 結果を「アプリ名」とする
10. **辞書の値を取得**：キー `urls`、辞書＝設定
11. **辞書の値を取得**：キー＝「アプリ名」（変数）、辞書＝手順10の結果
12. **URLを開く**：手順11の結果

アクションボタンやホーム画面のウィジェットにこのショートカットを割り当てれば、今と同じ操作で起動できます。

## 3. 各アプリの起動方法

アプリごとに、次の2つから起動方法を選べます。

- **URLスキーム**：`paypay://` のようなURLで直接開きます。速いのですが、スキームを公開していないアプリが多く、カタログの値はネット上の情報を元にした候補です。PWAの「試す」で開けたものは「確認済み」になります。
- **個別ショートカット経由**：中身が「Appを開く」1つだけのショートカットを作り、それを呼び出します。URLスキームが分からないアプリでも確実に開けます。カタログでURLが空のアプリは、この方法が初期値になります。

個別ショートカットは、ショートカットAppで新規作成し、「Appを開く」アクションで対象アプリを選び、PWAに表示された名前（例：`開く_楽天ペイ`）で保存します。アプリを追加したときに作るのは、この1アクションだけです。

## 最速で起動するための工夫

| 操作 | タップ数 | 仕組み |
| --- | --- | --- |
| よく使うアプリ（★）を開く | 1 | PWAを開いた瞬間に画面下側に並ぶ。ショートカットでも最初のメニューの先頭に「★ よく使う」が出る |
| グループからアプリを開く | 2 | 開いた瞬間に大きなグループボタンが出る。押すとそのグループのアプリだけが並ぶ |
| グループ専用アイコンから開く | 1 | `?g=決済` のようにURLにグループ名を付けてホーム画面に追加すると、そのグループのアプリ一覧から始まる |

- ボタンは片手の親指で届くよう、画面の下側に寄せています。
- アプリを起動してPWAに戻ると、次回は最初の画面（よく使う＋グループ）から始まります。
- アプリのあるグループが1つだけで★も無い場合は、グループ選択を飛ばしてアプリ一覧を直接出します。
- 編集は右上の鉛筆ボタンから開きます。起動画面には編集用の部品を置いていません。
- ★は「編集」でアプリの左の☆を押して付けます。ショートカット側は手順を変えずに、送った設定で自動的に反映されます。

## 設定ファイルの形式

ショートカットはリストで順番を、辞書で名前とURLの対応を読みます。

```json
{
  "version": 1,
  "order": ["決済", "ポイント"],
  "apps": {
    "決済": ["PayPay", "楽天ペイ"],
    "ポイント": ["楽天ポイントクラブ"]
  },
  "urls": {
    "PayPay": "paypay://",
    "楽天ペイ": "shortcuts://run-shortcut?name=%E9%96%8B%E3%81%8F_%E6%A5%BD%E5%A4%A9%E3%83%9A%E3%82%A4",
    "楽天ポイントクラブ": "shortcuts://run-shortcut?name=..."
  }
}
```

## 実機で確認が必要な点

- 「ショートカットに送る」で、ショートカットにテキスト入力が渡るか（`shortcuts://run-shortcut?...&input=text` は[Apple公式のURLスキーム](https://support.apple.com/guide/shortcuts/apd624386f42/ios)です）。渡らない場合は、PWAの「ファイルで保存」で `iCloud Drive/Shortcuts/payment-launcher.json` に保存しても同じ結果になります。
- 個別ショートカット経由で開くとき、ショートカットAppが一瞬表示されるかどうか。
- カタログのURLスキーム候補（PayPay、メルカリ、LINE、Wallet）が現在も使えるか。
